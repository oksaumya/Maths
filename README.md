# 📐 Discrete Mathematics – Complete Study Notes

> Comprehensive B.Tech study notes covering all major topics in Discrete Mathematics.  
> Clean HTML format with worked examples, theorems, and practice Q&A.

---

## 📖 What's Inside

| Unit | Topics Covered |
|------|---------------|
| **Unit 1 – Logic** | Propositional Logic, Truth Tables, Predicate Logic, Quantifiers, Boolean Algebra |
| **Unit 2 – Proofs** | Axiomatic Systems, Rules of Inference, Direct/Contradiction/Induction Proofs, Loop Invariants |
| **Unit 3 – Set Theory** | Russell's Paradox, Countability, Cantor's Diagonal Argument, Halting Problem |
| **Unit 4 – Abstract Algebra** | Groups, Rings, Fields, Cyclic Groups, Lagrange's Theorem, Diffie-Hellman Cryptography |
| **Unit 5 – Advanced Counting** | Recurrence Relations, Master Theorem, Generating Functions |

## ✨ Features

- **Sticky sidebar** with anchor navigation to every section
- **Color-coded blocks** — Definitions (blue), Theorems (green), Examples (orange), Q&A (purple)
- **Practice questions** with click-to-reveal step-by-step solutions
- **MathJax** rendering for all mathematical symbols and equations
- **Responsive layout** — works on desktop and mobile

## 🚀 How to Use

1. Clone or download this repository
2. Open `index.html` in any browser
3. No server or installation required — fully self-contained

```bash
git clone https://github.com/oksaumya/discrete-mathematics-notes.git
cd discrete-mathematics-notes
open index.html
```
